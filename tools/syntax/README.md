# Локальная проверка синтаксиса (без NDK)

    sh tools/syntax/check.sh                 # main.cpp, game.cpp, draw.cpp
    sh tools/syntax/check.sh jni/src/game.cpp

Что это и зачем. Настоящая сборка — `ndk-build` в CI (arm64-v8a, android-24).
Ждать её на каждую правку дорого, а ошибки вида «не объявлено имя», «не сошлись
аргументы printf», «тип не тот» ловятся обычным `g++ -fsyntax-only`, если
подменить системные заголовки Android заглушками из `stub/`.

`stub/` — это НЕ часть сборки: заголовки подключаются только ключом `-I` из
`check.sh`, в `ndk-build` они не попадают. Внутри ровно те типы, функции и
константы, которыми пользуется код (`ANativeWindow`, `EGL*`, `gl*`, `SL*`,
`__system_property_get`), поэтому проверка находит настоящие ошибки в нашем
коде, а не ругается на отсутствующий NDK.

Проверка НЕ покрывает: поведение (тесты — `sh tools/farm/run.sh`), линковку,
реальные смещения и всё, что зависит от архитектуры.
