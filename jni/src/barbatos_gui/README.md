# Barbatos GUI

В проект добавлен Dear ImGui-рендерер Barbatos (`barbatos_gui_reconstructed.*`). Он повторяет навигацию Home / Draw / Aim / Items / Settings, палитру, переключатели, слайдеры, выбор файлов и диалоги обновления. Модель состояния отделена от игровых действий: существующий код остаётся владельцем эффектов, поэтому замена отрисовки не меняет поведение функций.

Файл подключён в `Android.mk` вместе с адаптером `imgui_stdlib.cpp`. Текстуры передаются через `barbatos_gui::TextureRegistry`, а действия возвращаются флагами `GuiState::settings`, `GuiState::aim`, `GuiState::draw` и `GuiState::update`.

Интерфейс намеренно не выполняет I/O, не читает память и не запускает игровые операции сам — это сохраняет действующие обработчики проекта и позволяет подключить новый внешний вид без изменения логики.
