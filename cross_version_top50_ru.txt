ОБОЗНАЧЕНИЯ

F1 — имя поля и object offset полностью совпадают в release и beta.
F2 — поле находится в производном классе со сдвинутым layout; offset beta нужно брать отдельно.
R1 — уникальное native-сопоставление: один beta RVA после фильтрации по классу, сигнатуре и AArch64 fingerprint.
R2 — точное правило re-identification: declaring class + canonical signature + native fingerprint; при коллизии дополнительно использовать Mirror reader/writer и обращения к полям.
R3 — generated Mirror wrapper; сопоставлять по serialized reader sequence, арности и implementation call target.

client/server:
- h — локальный якорь или локальный эффект подтверждён.
- m — локальная часть ясна, но остаётся проверка серверной валидации.
- l — серверная фиксация маловероятна без дополнительного server-side условия.
- n/a — только чтение, визуал или локальная функция.
