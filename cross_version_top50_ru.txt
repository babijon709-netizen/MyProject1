CROSS-VERSION TOP: RELEASE 11949 -> BETA 11957

полный список понятных функций и технических якорей для расширения чита.

исходные материалы:
- release: dump11949.7z
- beta: dumpbeta11957.7z
- проверены dump.cs, il2cpp.h, script.json и оба libil2cpp.so
- отчёт подготовлен отдельно от исходных dump-файлов

важно:
- RVA ниже — виртуальный адрес функции из script.json/dump.cs.
- RVA не равен смещению файла Offset из комментария dump.cs.
- beta dump.cs не сохраняет [Command], [TargetRpc] и [ClientRpc].
- beta network-методы сопоставлены по классу, сигнатуре, нормализованному AArch64 fingerprint и Mirror reader/writer helper-методам.

имена вроде QCI, QFe, QnZ и Uug — это обфусцированные имена из dump.cs, их нельзя осмысленно перевести как обычные названия. ниже переведено назначение каждой функции, а техническое имя оставлено рядом для поиска по dump и RVA. для R2 точный смысл помечен как предварительный, потому что одинаковая сигнатура встречается у нескольких методов.

ОБОЗНАЧЕНИЯ ЯКОРЕЙ

F1 — имя поля и offset объекта полностью совпадают в release и beta.
F2 — поле находится в производном классе со сдвинутым layout; beta offset нужно брать отдельно.
R1 — уникальное сопоставление native-кода: после фильтрации по классу, сигнатуре и AArch64 fingerprint остаётся один beta RVA.
R2 — точное правило повторной идентификации: класс + нормализованная сигнатура + native fingerprint; при коллизии дополнительно использовать Mirror reader/writer и обращения к полям.
R3 — сгенерированный Mirror wrapper; сопоставлять по последовательности чтения, количеству параметров и вызываемой реализации.

уверенность клиент/сервер:
- h — локальный якорь или локальный эффект подтверждён.
- m — локальная часть ясна, но остаётся проверка серверной валидации.
- l — серверная фиксация маловероятна без дополнительного server-side условия.
- n/a — только чтение, визуал или локальная функция.
