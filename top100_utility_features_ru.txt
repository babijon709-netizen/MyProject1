TOP 100 ПОЛЕЗНЫХ NON-RAGE ФУНКЦИЙ ДЛЯ ЧИТА
UTILITY / INFORMATION / QUALITY-OF-LIFE SHORTLIST: RELEASE 11949 -> BETA 11957

это отдельный список без rage-функций. здесь нет изменения урона, боевой
скорости, noclip, silent aim, teleport или автоматического боевого abuse.
приоритет отдан ESP, информации, навигации, loot UX, строительству, транспорту,
accessibility, read-only telemetry и стабильной архитектуре профилей.

все пункты — кандидаты для реализации. запись в игру допустима только через
существующий g_mem/HeapMemory gate, с revalidation, readback и restore. пункты
с Command/RPC сначала оставлять в preview/read-only режиме.

ОБОЗНАЧЕНИЯ

- F1 — поле/offset совпадает в release и beta.
- F2 — производный layout с beta-сдвигом; offset брать отдельно.
- R1 — unique native mapping release RVA -> beta RVA.
- R2 — сигнатуры недостаточно: нужны class, full signature, AArch64 fingerprint,
  Mirror reader/writer и field references.
- h — локальный эффект подтверждён; m — локальная часть ясна; l — возможна
  server-side correction; n/a — чтение, визуал или app-side функция.
- fast-reload сохраняется как отдельное имя существующей неполной функции.

ПОРЯДОК РЕАЛИЗАЦИИ

1. сначала 001-030: это read-only ESP, item data, player state, viewmodel и локальные utility overlays.
2. затем 031-060: навигация, markers, building и transport; все графы строить из проверенных identities.
3. затем 061-080: accessibility и combat telemetry; не превращать telemetry writer в gameplay modifier.
4. затем 081-090: automation только с preview и явным подтверждением пользователя; никаких автоматических боевых действий.
5. 091-100: diagnostics/profile infrastructure; использовать его до добавления новых memory writers.

НЕ ИСПОЛЬЗОВАТЬ КАК GAMEPLAY TOGGLE

- FPMotion.runReloadOffset и FPMotion.m_AimOffset: это TransformOffset, а не gameplay flags.
- PlayerInputHandler.SprintMode +0xA8: это input/state поле, не доказанный toggle.
- TargetRpc/ClientRpc: это notification/state delivery, а не готовая server-authoritative команда.
- unknown release/beta build: read-only mode до прохождения offset/class validation.
